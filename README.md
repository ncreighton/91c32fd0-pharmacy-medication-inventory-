# Pharmacy Medication Inventory and Reorder Bot

Telegram bot for independent pharmacies and compounding labs tracking medication inventory and automating reorder workflows. Staff scan medication barcodes to log stock levels, bot sends low-stock alerts at configurable thresholds, generates purchase orders to preferred suppliers via email, tracks pending orders and ETA, logs controlled substance inventory with signature capture, and sends daily inventory summary to the pharmacist-in-charge. Supports multi-location pharmacy networks with shared inventory visibility and transfer requests between branches.

## Setup
1. Set `TELEGRAM_BOT_TOKEN` in `.env`
2. `pip install -r requirements.txt`
3. `python main.py`
